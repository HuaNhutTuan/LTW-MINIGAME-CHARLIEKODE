MỤC LỤC & TỔNG QUAN KIẾN TRÚC

Ứng dụng được thiết kế theo mô hình chuẩn của Windows Forms với các thành phần cốt lõi:

  1. GameMode.cs: Enum định danh 2 chế độ chơi (Ghép cặp trí nhớ & Lật số tiến lên).
  2. FormMenu.cs: Màn hình chọn chế độ & cấu hình độ khó, được xây dựng theo mô hình 2 Panel lồng nhau (không cần mở thêm Form trung gian).
  3. FormGame.cs: Màn chơi chính hiển thị Header thông tin và sinh động ma trận thẻ bài trên Panel.

GIAI ĐOẠN 3: THIẾT KẾ MÀN CHƠI CHÍNH (FormGame)

1. Kéo thả Header Dashboard (pnlHeader)

Panel trên cùng gắn chặt vào đầu Form (Dock = Top, Chiều cao: 115px, Nền trắng White, Viền: FixedSingle):

  • lblMode & lblLevel: Hiển thị chế độ chơi hiện tại và Cấp độ ma trận.
  • lblStatus & lblScore: Hiển thị số cặp đã ghép (Game 1) / số tiếp theo (Game 2) và điểm số.
  • lblTime: Hiển thị thời gian còn lại (chuyển sang màu đỏ khi còn ≤ 5 giây). Anchor: Top, Right.
  • btnRestart & btnBack: Nút chơi lại và thoát về menu. Anchor: Top, Right.
  • prgTime (ProgressBar): Thanh thời gian trực quan. Anchor: Bottom, Left, Right.

2. Kéo thả Bàn Cờ (pnlBoard) & 3 Timer

  • pnlBoard (Panel): Size: 620, 620, Location: (42, 135), Anchor = None để luôn nằm chính giữa. BackColor: RGB(232, 238, 245).
  • tmrPreview: Timer đếm 2000ms (2 giây) nhìn trước các mặt thẻ.
  • tmrCountdown: Timer đếm ngược 1000ms (1 giây) trừ dần thời gian còn lại.
  • tmrFlipBack: Timer 600ms chờ người chơi quan sát khi lật sai trước khi úp thẻ lại.

GIAI ĐOẠN 4: CHI TIẾT LOGIC CODE & THUẬT TOÁN

1. Thuật toán Fisher-Yates xáo trộn thẻ bài

Tạo danh sách giá trị và đảo vị trí ngẫu nhiên không thiên lệch:

private List<int> GenerateShuffledValues(int totalCards)
{
    List<int> values = new List<int>();
    if (currentMode == GameMode.MemoryMatch)
    {
        int pairCount = totalCards / 2;
        for (int i = 1; i <= pairCount; i++)
        {
            values.Add(i);
            values.Add(i); // Thêm theo cặp
        }
    }
    else
    {
        for (int i = 1; i <= totalCards; i++)
            values.Add(i); // Dãy số liên tục 1, 2, ..., N
    }

    // Fisher-Yates Shuffle
    for (int i = values.Count - 1; i > 0; i--)
    {
        int swapIndex = rng.Next(i + 1);
        int temp = values[i];
        values[i] = values[swapIndex];
        values[swapIndex] = temp;
    }
    return values;
}

3. Chi tiết xử lý Logic từng Game

🧠 GAME 1: LẬT THẺ GHÉP CẶP TRÍ NHỚ (Memory Match)
  • Lần click 1: Lưu lại firstCard = clickedCard;
  • Lần click 2: Gán secondCard = clickedCard; và so sánh:
    • Khớp (Tag trùng nhau): Đổi BackColor = Color.LightGreen, Enabled = false, cộng +25 điểm, tăng biến pairsFound++. Kiểm tra nếu ghép đủ 100% thì thắng màn và tăng cấp độ.
    • Không khớp: Trừ -5 điểm, khóa bàn chơi isBusy = true, kích hoạt tmrFlipBack (600ms) để úp 2 thẻ lại.
private void HandleMemoryMatch(Button clickedCard)
{
    if (firstCard == null)
    {
        firstCard = clickedCard;
        return;
    }
    secondCard = clickedCard;

    if ((int)firstCard.Tag == (int)secondCard.Tag)
    {
        firstCard.BackColor = Color.LightGreen;
        secondCard.BackColor = Color.LightGreen;
        firstCard.Enabled = false;
        secondCard.Enabled = false;
        firstCard = null;
        secondCard = null;

        pairsFound++;
        score += 25;
        UpdateStatusLabel();

        if (pairsFound == (rows * cols) / 2)
        {
            tmrCountdown.Stop();
            AdvanceToNextLevel();
        }
    }
    else
    {
        score = Math.Max(0, score - 5);
        UpdateStatusLabel();
        isBusy = true;
        tmrFlipBack.Interval = 600;
        tmrFlipBack.Start();
    }
}
🔢 GAME 2: LẬT THẺ TIẾN LÊN THEO THỨ TỰ (Sequential Order)
  • So sánh (int)clickedCard.Tag == expectedNumber:
    • Đúng thứ tự: Đổi BackColor = Color.LightGreen, Enabled = false. Cộng +10 điểm cho số 1, +5 điểm cho số tiếp theo, hoặc thưởng chuỗi liên tiếp +(5 + combo). Tăng expectedNumber++. Kiểm tra nếu đạt số cuối thì thắng màn.
    • Sai thứ tự: Trừ -3 điểm, reset chuỗi liên tiếp về 0, đổi màu thẻ bấm sai sang Color.LightCoral (đỏ nhạt). Chờ 600ms qua tmrFlipBack:
      • Nếu bật Hardcore: Úp toàn bộ bàn cờ về số 1!
      • Nếu chơi thường: Úp lại thẻ bấm sai và lùi lại 2 bước đã lật đúng gần nhất.
private void HandleSequentialOrder(Button clickedCard)
{
    int cardValue = (int)clickedCard.Tag;
    if (cardValue == expectedNumber)
    {
        clickedCard.BackColor = Color.LightGreen;
        clickedCard.Enabled = false;
        consecutiveCorrect++;

        if (expectedNumber == 1) score += 10;
        else if (consecutiveCorrect >= 2) score += (5 + consecutiveCorrect);
        else score += 5;

        expectedNumber++;
        UpdateStatusLabel();

        if (expectedNumber > (rows * cols))
        {
            tmrCountdown.Stop();
            AdvanceToNextLevel();
        }
    }
    else
    {
        score = Math.Max(0, score - 3);
        consecutiveCorrect = 0;
        UpdateStatusLabel();

        clickedCard.BackColor = Color.LightCoral;
        firstCard = clickedCard;
        isBusy = true;
        tmrFlipBack.Interval = 600;
        tmrFlipBack.Start();
    }
}

4. Tự động nâng cấp độ và mở rộng ma trận (AdvanceToNextLevel)

private void AdvanceToNextLevel()
{
    MessageBox.Show($"🎉 Chúc mừng! Bạn đã hoàn thành Cấp độ {currentLevel}!\nĐiểm số: {score}");
    currentLevel++;

    // Tự động mở rộng dòng hoặc cột
    if (rows < cols) rows++;
    else cols++;

    // Game 1: Bắt buộc tổng số ô chẵn
    if (currentMode == GameMode.MemoryMatch && (rows * cols) % 2 != 0)
        cols++;

    if (rows > 8) rows = 8;
    if (cols > 8) cols = 8;

    InitializeBoard(); // Dựng lại bàn chơi mới
}

3 Bí quyết Cân chỉnh Nút bấm Chuyên nghiệp:

  1. Loại bỏ hoàn toàn viền 3D cổ điển: Luôn đặt FlatStyle = FlatStyle.Flat và FlatAppearance.BorderSize = 0 (hoặc 1 với màu viền tinh tế như Color.SteelBlue).
  2. Con trỏ chuột tương tác: Đặt Cursor = Cursors.Hand cho mọi thẻ bài và nút bấm để tạo cảm giác phản hồi tự nhiên cho người dùng.
  3. Font chữ Unicode sắc nét: Sử dụng phông Segoe UI Emoji với kích cỡ động Math.Max(10f, Math.Min(w, h) / 3f) để các icon động vật, hoa quả luôn tự căn chỉnh vừa vặn với từng ô cờ.
